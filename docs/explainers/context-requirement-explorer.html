Context Requirement Explorer

One context_required call, followed end to end. Set the request, watch each gate and stage decide, and read the artifact that comes back. Every answer is one of three things: cited context, governed absence, or an empty optional result.

Stages, gates, reason codes, weights, and the hash rule mirror crates/ck-app/src/context.rs, crates/ck-mcp/src/cep_bundle.rs, and crates/ck-mcp/src/agentic_capability_loop.rs. Candidate chunks, scores, ages, and token counts are illustrative fixtures; semantic merging is not simulated.
